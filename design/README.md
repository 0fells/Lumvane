# Lumvane design

**Русский** | [English](#english)

Иконка "флюгер", общая для Windows- и Android-версии: стрела флюгера на тёмно-фиолетовой плитке, наконечник светится.

| Файл | Что это |
|---|---|
| `icon.svg` | исходник значка, сетка 512x512 |
| `icon-512.png` | значок в PNG (генерируется `make_icons.ps1`) |
| `tray.svg` | флюгер без плитки для трея (жирная форма) |
| `make_icons.ps1` | рисует `windows/res/Lumvane.ico`, значок окна `windows/res/public/App.png` и `App-32.png`, значки трея `windows/res/public/<режим>.png` и `icon-512.png` |
| `avatar-800.gif`, `anim/` | анимированная аватарка (порыв ветра качает флюгер) и её генератор |

## Геометрия

Детали в сетке 512 до поворота; весь флюгер повёрнут на -30 градусов вокруг точки 256,256.

- хвост `64,214 150,214 176,256 150,298 64,298 98,256`, цвет `#5C7CFF`;
- древко: прямоугольник `150,244` 220x24, скругление 12, цвет `#F3EEFF`;
- наконечник `352,196 456,256 352,316`, цвет `#B79CFF`;
- ось: окружность радиусом 30 в центре, заливка цветом плитки, обводка 14 цветом древка;
- плитка `16,16` 480x480, скругление 112, цвет `#221A4D`.

Жирная форма для 32 px и меньше, трея и монохрома: древко `150,236` 220x40 со скруглением 20, наконечник `352,186 466,256 352,326`, ось сплошным кругом радиусом 40.

Значок в трее меняет цвет по режиму (хвост и остальной флюгер): работает `#5BD68A`/`#14A050`, выключено `#9AA0A8`/`#6B7178`, прокси `#4DA3FF`/`#1F6FE5`, DNS `#B48CFF`/`#7C4DFF`, прокси и DNS `#B48CFF`/`#1F6FE5`, Tun `#FF6B6B`/`#D92B2B`. Окно и панель задач всегда показывают иконку `App.png` с плиткой. В заголовке окна флюгер без плитки рисуется вектором (`windows/src/ui/widget/TitleBar.cpp`) в средних тонах, которые видны и на светлом, и на тёмном фоне: хвост `#5C7CFF`, древко и колечко оси `#6A4FE6`, наконечник `#A68BFF`; древко 32 и колечко 18 чуть толще, чем в большой иконке. В обеих темах он одинаковый, цвет фона берёт только середина колечка.

На Android кнопка подключения во включённом состоянии повторяет иконку: флюгер в своих цветах (`ic_lumvane_vane.xml`) на цвете плитки; в выключенном — серый силуэт той же формы (`ic_lumvane_logo.xml`).

Акцент интерфейса под иконку: `#5B3FD6` в светлой теме, `#A996FF` в тёмной.

## Как поменять иконку

1. Поправить `icon.svg` и `tray.svg`, те же координаты и цвета в `make_icons.ps1`.
2. Windows: `powershell -File design\make_icons.ps1`.
3. Android: перерисовать по координатам выше векторные значки в `android/app/src/main/res/drawable`: `ic_launcher_background.xml`, `ic_launcher_foreground.xml` (адаптивный значок, масштаб 0.16, сдвиг 13.04), `ic_launcher_monochrome.xml` (жирная форма одним цветом), `ic_stat_lumvane.xml` (уведомления и плитка, жирная форма), `ic_lumvane_vane.xml` (кнопка подключения во включённом состоянии, цветной флюгер), `ic_lumvane_logo.xml` (выключенная кнопка; прозрачность: хвост 0.55, наконечник 0.8, древко и колечко 1).
4. Аватарка: в `anim/` выполнить `npm install`, затем `npm run build`.

## English

The "weather vane" icon shared by the Windows and Android apps: a vane arrow on a deep violet tile, with a glowing head.

| File | What it is |
|---|---|
| `icon.svg` | icon source, 512x512 grid |
| `icon-512.png` | the icon as PNG (generated by `make_icons.ps1`) |
| `tray.svg` | the vane without the tile, for the tray (bold form) |
| `make_icons.ps1` | renders `windows/res/Lumvane.ico`, the window icon `windows/res/public/App.png` and `App-32.png`, tray icons `windows/res/public/<mode>.png` and `icon-512.png` |
| `avatar-800.gif`, `anim/` | animated avatar (a gust of wind swings the vane) and its generator |

### Geometry

Parts on the 512 grid before the turn; the whole vane is turned -30 degrees about 256,256.

- tail `64,214 150,214 176,256 150,298 64,298 98,256`, colour `#5C7CFF`;
- shaft: rectangle `150,244` 220x24, corner radius 12, colour `#F3EEFF`;
- head `352,196 456,256 352,316`, colour `#B79CFF`;
- pivot: circle of radius 30 in the centre, filled with the tile colour, 14 wide outline in the shaft colour;
- tile `16,16` 480x480, corner radius 112, colour `#221A4D`.

Bold form for 32 px and below, the tray and monochrome: shaft `150,236` 220x40 with corner radius 20, head `352,186 466,256 352,326`, pivot as a solid circle of radius 40.

The tray icon changes colour by mode (tail and the rest of the vane): running `#5BD68A`/`#14A050`, off `#9AA0A8`/`#6B7178`, proxy `#4DA3FF`/`#1F6FE5`, DNS `#B48CFF`/`#7C4DFF`, proxy and DNS `#B48CFF`/`#1F6FE5`, Tun `#FF6B6B`/`#D92B2B`. The window and the taskbar always show `App.png` with the tile. The title bar draws the vane without the tile as vectors (`windows/src/ui/widget/TitleBar.cpp`) in mid tones that read on both the light and the dark bar: tail `#5C7CFF`, shaft and pivot ring `#6A4FE6`, head `#A68BFF`; shaft 32 and ring 18 are a little thicker than in the large icon. It is the same in both themes; only the middle of the ring takes the bar colour.

On Android the connect button, when connected, repeats the icon: the vane in its own colours (`ic_lumvane_vane.xml`) on the tile colour; when off, a grey silhouette of the same shape (`ic_lumvane_logo.xml`).

UI accent to match the icon: `#5B3FD6` in the light theme, `#A996FF` in the dark one.

### Changing the icon

1. Edit `icon.svg` and `tray.svg`, and the same coordinates and colours in `make_icons.ps1`.
2. Windows: `powershell -File design\make_icons.ps1`.
3. Android: redraw the vector icons in `android/app/src/main/res/drawable` from the coordinates above: `ic_launcher_background.xml`, `ic_launcher_foreground.xml` (adaptive icon, scale 0.16, offset 13.04), `ic_launcher_monochrome.xml` (bold form in one colour), `ic_stat_lumvane.xml` (notification and tile, bold form), `ic_lumvane_vane.xml` (connected button, the vane in colour), `ic_lumvane_logo.xml` (switched-off button; opacity: tail 0.55, head 0.8, shaft and ring 1).
4. Avatar: run `npm install`, then `npm run build` in `anim/`.
